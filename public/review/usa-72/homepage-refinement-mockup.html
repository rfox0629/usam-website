Homepage Refinement Mockup

This is a standalone static mockup of the current usamissionaries.org homepage. The layout, pacing, visual system, and nearly all copy are untouched. Six targeted edits clarify that USA Missionaries is a national missionary network and ecosystem — not only kitchen-table ministry. Nothing here has been wired into the live site.

Prepared for Ryan Fox · usamissionaries.org homepage (app/page.tsx) · 2026-07-22

What Changed (6)

1Organization statement — replaced the inaccurate “Not an organization. A deployment.” line.
2Table framing — the table stays central, but copy now names it as training ground, not the whole identity.
3Who is a USA Missionary — one clarifying paragraph: a trained, commissioned role, not a broad label.
4National structure — added a brief line on leadership team, regional directors, state teams, and the 3-cities-per-state goal.
5System → Ecosystem — renamed and reframed to cover both the missionary team and partner ministries.

Hero: “The Mission Is Active,” Matthew 28:19–20, both CTAs
The full Field Intelligence / state-of-America data section
The USA map + kitchen table visual, including “It Starts Here”

Final CTA: “You Were Sent” / Join the Mission
Typography (Oswald/Rajdhani), gold/black palette, section pacing
